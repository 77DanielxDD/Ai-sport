# 验收截图清单（论文可直接引用）

> 建议截图分辨率：1920x1080，统一浏览器缩放 100%。

## A. 功能闭环
- [ ] 登录页：输入账号密码并成功登录
- [ ] 上传页：选择动作类型 + 上传 15 秒内视频
- [ ] 任务页：状态从 `UPLOADED/PROCESSING` 轮询到最终状态
- [ ] 报告页：展示关键帧、角度趋势图、文字建议（中文）
- [ ] 历史页：单条删除 + 按筛选批量删除

## B. 异步与异常场景
- [ ] 任务取消：点击“取消任务”后状态变 `CANCELLED`
- [ ] 重试分析：`FAILED/CANCELLED` 后点击“重试分析”
- [ ] 轮询 202 返回：展示 `retryAfterMs` 场景
- [ ] 错误提示：上传失败/分析失败页面提示

## C. 实验与性能
- [ ] 实验页：发起评测 + 展示汇总指标
- [ ] JMeter 报告页：吞吐、平均、P95 指标
- [ ] 系统健康页：Java/Python/MQ 检查信息

## D. 后台验证（可附加）
- [ ] `GET /api/videos/{id}/analysis` 的 200/202/409/500/404 样例
- [ ] `/media/**` 图片可访问截图
- [ ] 数据库关键表截图：`exercise_videos`、`analysis_tasks`
