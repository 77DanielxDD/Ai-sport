上传训练视频，获取逐次多维度动作评分。结合 Agent + RAG 的智能问答，让每一次训练都有数据可循。

Features
核心能力
8 种健身动作的 AI 姿态分析，逐次多维度评估 + Agent 智能问答
🎥

视频上传引导

拍摄建议、本地预览、时长/大小校验、实时上传进度条。支持 30s / 150MB 视频。

⏱

异步任务进度

6 阶段进度追踪，RabbitMQ 解耦上传与分析，自动轮询，失败重试。

📊

多维度评分

逐次评估深度 (45%)、稳定性 (20%)、对称性 (20%)、节奏加成，加权综合评分。

🧠

Agent + RAG 问答

5 工具编排（知识搜索、趋势、历史、记忆、报告），DeepSeek LLM 流式输出诊断与训练计划。

👁

报告对比

9 区对比分析：结论、指标 delta、四维条形、逐次表格、关键帧、趋势、问题变化、建议、排名。

🛡

安全 & 监控

JWT 认证、速率限制、管理后台、COS 对象存储、Actuator 健康监控、JMeter 压测。
