## Git Workflow

- Before making any code changes, run `git pull --ff-only origin main` to sync the latest code.
- After completing any code update, run verification appropriate to the change, then automatically commit the changes to git.
- Do not wait for an extra user confirmation before committing completed code updates, unless the user explicitly asks not to commit.
- Do not commit unrelated local files or generated artifacts unless they are part of the requested change.
