# AI-Sport

基于 Spring Boot + RabbitMQ + Python AI 的运动视频分析系统

## 运行方式
1. 启动后端：Run AiSportApplication
2. 访问地址：http://localhost:8080

## 云端部署
- 云端部署文件：`docker-compose.cloud.yml`
- 环境变量模板：`deploy/cloud/.env.example`
- 启动脚本：`scripts/cloud_up.sh`
- 停止脚本：`scripts/cloud_down.sh`
- 详细步骤：`docs/cloud_deployment.md`
